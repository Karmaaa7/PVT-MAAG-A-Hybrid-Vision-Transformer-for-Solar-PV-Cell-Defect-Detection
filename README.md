# PVT-MAAG: A Hybrid Vision Transformer for Solar PV Cell Defect Detection

## Overview

This project explores deep learning-based defect detection in photovoltaic (PV) cells using a hybrid vision-based approach. The project focuses on developing and experimenting with a model for identifying defects in solar PV cell images.

The implementation and experiments were conducted as part of the **CSE465 course project** at North South University.

## Project Objectives

- Explore deep learning techniques for solar PV cell defect detection.
- Implement and experiment with a hybrid vision-based detection architecture.
- Train and evaluate the model using a photovoltaic cell defect dataset.
- Investigate the application of computer vision to automated PV defect inspection.
